# DBS_elec_localization

## Overview

This repository provides MATLAB tools for localizing deep brain stimulation (DBS) electrodes using preoperative MRI and postoperative CT imaging data. It supports importing DBS lead coordinates, visualizing electrode placements, and determining microelectrode recording (MER) positions.

## Repository Structure

```bash
electrode-localization/
├── add_points_to_brain.m       # Script to add electrode points to brain visualization
├── brain_generic.fig           # Generic brain figure for plotting electrodes
├── dbs_template.mgz            # Template MRI volume for DBS localization
├── determine_mer_position.m    # Determine MER positions relative to DBS leads
├── importDBSlead.m             # Import DBS lead coordinates from imaging data
├── Electrode_Localization_Procedure.docx  # Detailed procedure documentation
└── README.md                   # Project info
```
